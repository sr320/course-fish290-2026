## Citation format in feedback

In the feedback `.txt`, each improvement bullet must end with a bracketed reference, semicolon-separated when multiple:

```
- The introduction states the hypothesis only in the final paragraph; move it earlier to anchor the reader.  [ref: readings/The Introduction Section.pdf; lectures/290 Week 2a.pdf]
```
